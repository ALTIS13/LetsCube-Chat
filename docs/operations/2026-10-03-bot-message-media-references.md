## Contract

- `private.bot_media_url_pointer(text)` returns a bounded decoded bucket/path or
  no row for unsupported input. It preserves the exact accepted single-pass ASCII
  subset in [the advisory preflight](../../scripts/bot-media-reference-preflight.sql).
- `private.bot_message_media_references(text,text,text,jsonb)` observes canonical
  bucket/path, legacy URL and preview independently. Result columns are
  `source_kind`, `bucket_id`, `object_path`, `generation_id`, `reference_state`,
  `hold_reason`. Duplicate object pointers retain their separate source rows.
- Canonical/preview database paths are literal, never decoded, trimmed, case-folded
  or normalized. Null path means no canonical observation; an empty supplied path
  remains an invalid-path hold. Preview uses the parent bucket, never its own
  metadata bucket and never a fallback bucket.
- SQL null/JSON null metadata and a missing/null preview are absent observations.
  A malformed metadata container, nonobject preview, or missing/nonstring preview
  path produces a hold. Other metadata fields do not assert additional pointers.
- A registered observation identifies the exact immutable logical registry row,
  not a physical Storage incarnation or an admitted message edge. Unregistered
  paths in any bucket, missing buckets, invalid paths and unsupported URLs produce
  unresolved holds, never an empty-set absence result.
- Different known canonical and legacy-URL pointers make both observations
  ambiguous while retaining their paths and any generation IDs. A different
  preview path is not itself a conflict. Deleted rows with retained pointers
  still count; only the actual final scrub removes those observations.
- Both functions are private invoker functions owned by `postgres`, with client
  EXECUTE revoked. The decoder is immutable; registry lookup is
  [statement-stable](https://www.postgresql.org/docs/17/xfunc-volatility.html),
  not a wait/recheck or writer fence. No message trigger, membership authorization,
  Storage call, seal, deletion or quota release is added.
