## Критерий закрытия

На выделенной сборке явно разрешить манифест для Windows Edge, не меняя
каналы нативных приложений. До установки зафиксировать пустой `edge://apps`
в тестовом профиле и идентичность приложения (manifest ID + профиль).
Штатно установить, доказать запись в `edge://apps` и `display-mode: standalone`,
закрыть именно этот процесс и повторить запуск по app ID с отказом локального
прокси. Проверить главную и вход. Затем удалить только карточку тестового
приложения из этого профиля и проверить исчезновение записи и окна.
